标签页顺序

科技资讯来源

独立于财经时间线，每日按设定时间更新，也可在科技资讯标签页手动刷新。每行：名称 | HTTPS RSS/Atom URL；最多15个，留空关闭抓取。

行情图表周期

填写常用自然日天数，以逗号分隔，最多12个。分时与“最长”始终提供；最长会加载来源可获取的日线或净值历史，并显示实际日期与来源限制。

行情与数据源设置

按资产类别选择默认来源；也可为单个项目覆盖。修改地址仅改变请求位置，响应仍须符合所选来源格式。新闻与科技RSS可在上方独立修改。

模板需包含{symbol}，可选{period}；返回标准price/previousClose/quoteTime及history数据。仅填公开地址，不放密钥。

高级：修改各数据源基础地址

图表指标配置

输入EMA9、EMA21、MA5等，逗号分隔。周期1–999，最多12项；VWAP为来源提供的分时成交均价。勾选默认启用项，详情页切换也会保存。

分钟K线周期

分钟K线使用来源真实OHLC；场外基金、当前港美股及国际期货来源不支持时会禁用，不会用分时点伪造K线。

顶部展示行情

最多20个，支持指数、黄金、原油期货、股票、基金及加密货币。每张卡片标明币种、来源和报价时间；点击可查看历史图表。

按钮显示紧凑值，悬停查看精确数值和报价时间；数据可能延迟。Chrome 关闭或休眠期间无法更新。

自定义监控项目

输入代码自动识别名称与品种，点击添加立即保存并展示在行情监控表，无需再次保存设置。最多30项，支持股票、ETF、场外基金、黄金、国内外期货、加密货币和公开JSON数据源。

无需手填名称或品种。重名代码会提供匹配列表。

高级：手工项目与自定义 JSON 来源

自定义JSON字段：price、previousClose、quoteTime、currency，可选open/high/low/volume、history.minute/history.day。只填写公开URL，不放密钥。代码不确定时可先添加示例再修改。

美股与美国基金默认使用Nasdaq日线；Yahoo为可选海外来源，网络不可达时会显示错误，不会伪造历史。

Chrome 配置同步

先保存设置，再上传到 Chrome Sync，或拉取云端配置并应用。需要在 Chrome 登录同一账户并开启扩展同步。密钥、ChatGPT 登录凭据、新闻和聊天记录不参与同步。

配置存储在Chrome Sync，不是Google Drive文件。当前仅保存一份最新配置，上传会覆盖上一份；列表显示本浏览器可读取的同步副本，不代表服务器确认。两台设备需使用相同扩展ID并开启Chrome同步。

离线时 Chrome 会暂存上传，联网后同步；本插件无法确认 Google 服务器已收到。切换服务商或 API 地址时不会把本机密钥带到新接口。
